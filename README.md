# TheTroyGame

**TROY: Siege Defense** — сюжетная Tower Defence игра о Троянской войне с целевым временем полного прохождения около **2 часов**.

Игрок командует обороной Трои: от первых высадок греков и боёв на подступах к городу до штурма стен, появления великих героев, Троянского коня и финальной ночной обороны горящей Трои.

## Core Pillars

- ~120 минут на полную сюжетную кампанию.
- 7 глав с разными картами, правилами и темпом.
- Tower Defence + лёгкая RTS-механика героя.
- 6 типов оборонительных построек / отрядов.
- Обычные, тяжёлые, осадные и элитные враги.
- Герои-боссы: Менелай, Аякс, Одиссей, Ахилл.
- Динамические маршруты и изменение поля боя.
- Финальная survival-глава внутри Трои.
- Upgrade / Sell / способности героя / экономика / сюжетные события.
- Unity, одиночная игра.
