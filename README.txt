TheTGame

Unity 6 Tower Defense prototype.

Current gameplay foundation:
- dual enemy routes converging on one base
- 7 waves with Heavy enemies and final Boss
- Machine Gun / Cannon / Slow Tower
- build points, upgrades and sell
- Start Wave button and automatic inter-wave countdown
- pan / zoom camera
- runtime Canvas HUD
- Main Menu / Level Select / Settings / Pause / Victory / Game Over
- muzzle flash, hit and destruction effects
- generated runtime SFX without external audio files
- New Input System / Legacy Input compatible code paths

Main is the active solo-development branch.
